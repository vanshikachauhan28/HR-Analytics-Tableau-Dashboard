# HR-Analytics-Tableau-Dashboard
HR Analytics Dashboard built in Tableau to analyze workforce demographics, employee performance, salary, hiring trends, departments, locations, and employment details.

## Project Overview

This project is an interactive **Human Resources Analytics Dashboard built using Tableau** to analyze employee demographics, workforce composition, hiring trends, salary distribution, performance, and employee details.

The dashboard provides both a high-level overview of the workforce and a detailed employee-level view, allowing users to interactively filter and explore HR data.

---

## Project Objectives

The main objectives of this project were to:

- Analyze the overall employee workforce
- Compare hired and terminated employees
- Understand employee distribution across departments
- Analyze workforce demographics such as gender, age and education
- Examine the relationship between education and employee performance
- Analyze salary distribution across different age groups
- Identify workforce distribution by geographic location
- Explore employee-level information through interactive filters
- Build an interactive and user-friendly HR dashboard in Tableau

---

## Dashboard Overview

### 1. HR Overview Dashboard

The Overview dashboard provides a high-level summary of the organization's workforce.

### Key Metrics

- Active Employees
- Total Hires
- Total Terminations
- Department-wise Employee Distribution
- Workforce by Location

### Demographic Analysis

The dashboard analyzes:

- Gender distribution
- Age groups
- Education levels
- Education vs. Performance

### Income Analysis

The dashboard includes:

- Education vs. Gender salary analysis
- Age vs. Salary distribution
- Salary patterns across employees and job roles

### Geographic Analysis

Employee distribution is visualized geographically to compare workforce presence across different locations.

---

## 2. Employee Details Dashboard

The Details dashboard provides an employee-level view of the dataset.

Users can explore employees based on:

- Employee ID
- Name
- Gender
- Age Group
- Education Level
- Job Title
- Department
- State
- City
- Location
- Salary
- Employment Status
- Year of Hire
- Year of Termination
- Length of Employment

The dashboard also includes interactive filters for salary, employment duration, status, and other employee attributes.

---

## Interactive Features

The dashboard allows users to dynamically filter and explore the data using:

- Gender
- Employment Status
- Location
- Hire Date
- Department
- Job Title
- Education Level
- Age Group
- Salary
- Length of Employment

Dashboard elements can also be used as interactive filters to drill down into specific segments of the workforce.

The dashboard focuses on several important HR analytics areas:

### Performance
Examining the relationship between education levels and employee performance.

### Compensation
Analyzing salary patterns across age groups, education levels and job roles.

### Department Analysis
Comparing employee distribution across departments such as Operations, Sales, Customer Service, IT, Marketing, Finance and HR.

Understanding employee distribution across different states, cities and locations.
